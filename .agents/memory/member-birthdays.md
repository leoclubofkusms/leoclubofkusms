---
name: Member birthday requirement
description: The user's standing requirement for Nepali birthday entry when adding club members.
---

New member entries must require a birthday in the Nepali BS calendar from now on. Existing member records without a saved birthday should remain editable.

**Why:** The user asked for birthdays to be mandatory for new entries; retaining editability avoids blocking updates to older records.

**How to apply:** Require and validate a BS date on member creation. When editing legacy records that lack a birthday, allow other member fields to be updated.
